# llama-cpp-webui

## What
An easy management server for llama.cpp, but the backend binary build process is automated, so you're just one click away from running the latest fix of llama.cpp.

Includes:
- llama.cpp updater UI
- Model loader UI
- Huggingface downloader UI
- OpenAI-compatible REST endpoint for inference

## How to start
### Ubuntu/Debian
```
run.sh
```

### Windows 10/11
Will need admin privileges to install dependencies:
```
run.bat
```
